# Exams-Trainer
подготовка к егэ

ЕГЭ-Тренажёр

Для кого: Школьники 10–11 классов, готовящиеся к ЕГЭ.

Проблема: Задания в PDF, сайты в рекламе, непонятно, что проседает. С телефона неудобно, мотивации нет.

Что делает: Сайт-тренажёр. Выбираешь тему — решаешь — сразу видишь результат и ошибки. Есть пробник и прогресс.

Функции:
1. Тренажёр по темам с проверкой
2. Пробник на время
3. Прогресс по темам
4. Сохранённые задания

Почему Go:
· Мгновенная проверка
· Держит тысячи пользователей
· Воркеры для статистики
